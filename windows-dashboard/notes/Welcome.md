# Welcome to your Command Center 👋

This scratchpad lives in the `notes/` folder as plain Markdown — everything here
is saved to disk automatically while you type.

## Things to try

- **Overview** — live CPU/RAM/disk gauges, GPU stats, network speeds and weather.
  Drag cards by their headers to reorder them, or use the bottom-right corner to resize.
- **Terminal** (`Alt+1`) — real PowerShell/CMD tabs. `Ctrl+Shift+T` opens a new tab.
- **Files** — browse drives, preview text files, rename and delete (to the Recycle Bin).
- **Network** — ping, port list and a speed test.
- **System** — top processes, maintenance tasks and power controls.
- Settings (⚙) — theme, scan folders, GitHub token and more.

> Everything runs locally. The only outbound requests are the weather widget,
> the optional GitHub notifications and the speed test.

```text
Ctrl+K   command palette
Alt+1-6  switch views
```
